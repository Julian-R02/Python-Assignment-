# Course Student Checklist

This repository contains the course materials for **Methods: Python programming for economists**. Use the checklist below to track what is expected of you as a student.

## ✅ To-Do List

### Setup & Access
- [ ] Create a GitHub account (needed for the final assignment submission).
- [ ] Access JupyterLab via the university server (or use Google Colab if needed).
- [ ] Clone the course repository in JupyterLab:
  ```bash
  git clone https://github.com/janboone/Python-programming-for-economists.git
  ```
- [ ] (Optional) Clone the assignment repository:
  ```bash
  git clone https://github.com/janboone/python_assignments
  ```

### Course Workflow (Weekly)
- [ ] Follow the assigned DataCamp modules for the week.
- [ ] Take notes and save useful code snippets in your JupyterLab notebook.
- [ ] Work through the lecture notebook questions **before** the lecture week.
- [ ] Watch the related screencast(s) **only if** you get stuck.
- [ ] If still stuck, ask the chatbot or open a GitHub issue (describe what you tried and where you got stuck).

### Participation Requirements
- [ ] Attend or complete at least **1 Career Development workshop**.
- [ ] Attend or complete at least **1 Career Development event**.
- [ ] Participate in the Q&A-focused lectures if you need help.

### Knowledge & Skills Expectations
- [ ] Be comfortable with Python basics (syntax, functions, lists, dicts, arrays).
- [ ] Be able to use `numpy`, `pandas`, and `matplotlib` for data work and plotting.
- [ ] Understand basic economics concepts used in the notebooks (utility, welfare, supply/demand, Cournot, etc.).

### Key Dates (from schedule)
- [ ] Track lecture dates and topics in `Data Course/index.org`.
- [ ] Final assignment deadline: **2026-01-05**.
- [ ] Resit deadline: **2026-05-11**.

### Final Assignment
- [ ] Review the assignment instructions in the `python_assignments` repo.
- [ ] Practice solving and simulating an economics model in Python.
- [ ] Submit the final assignment via GitHub as instructed.
